Deploying your own copy? Set this up once
  1. Go to Google Cloud Console and create a project (or use an existing one).
  2. Under APIs & Services → Library, enable the Google Drive API.
  3. Under APIs & Services → Credentials, click Create Credentials → OAuth client ID, type Web application.
  4. Under Authorized JavaScript origins, add the exact URL this page is served from (e.g. your GitHub Pages URL, https://username.github.io) — Google OAuth won't work on a plain file:// path.
  5. Copy the Client ID it gives you and paste it into the GOOGLE_CLIENT_ID constant near the top of the <script> in this file, then redeploy. It's baked into the page, the same way it's done for you here — no per-device setup needed.

This device signs in automatically and stays synced on every visit — no toggle needed.
